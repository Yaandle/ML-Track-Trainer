Panorama Lab

Model and training method · Prototype 03

01 / Objective

Complete one lap of Mount Panorama as fast as possible without touching the wall, using the same GT3 physics a human driver uses.

02 / Technique

Neuroevolution

A population of neural-network drivers is simulated at once. The highest-scoring networks are kept, recombined and randomly mutated to form the next generation. There are no gradients: the only learning signal is each driver's total episode reward.

  • Why: simple, dependency-free, runs in the browser on the manual-driving physics, and the simulator is deterministic so fitness comparisons are clean.
  • Limits: sample-inefficient, scales poorly to large networks, and gives no credit assignment inside an episode.
  • Relation to RL: same goal (maximise expected return) via direct policy search. A network is the policy; evolution is the training method; RL is the wider framework. Here, selection and mutation between generations replace the per-agent policy update.
  • Next: port the environment to Python and compare against PPO on the same reward.

03 / Observations

Track-relative geometry, sampled at 30 Hz. No camera or ray-casting.

InputMeaning

04 / Network

Outputs: pedal (tanh; positive = throttle, negative = brake) and steering (tanh; positive = right). Both pass through the same control ramps as keyboard input.

05 / Reward function

Per step: progress × Δdistance − time × Δt − grass × Δt (grass applies only off the road). Terminal events add a one-off term.

06 / Evolution loop

  • Simulate every network in lockstep until all have ended.
  • Rank by total reward.
  • Keep the elites unchanged, add a few fresh random networks, and fill the rest with mutated (optionally crossed-over) children of the top share.
  • Shrink the mutation size each generation. Save the highest-reward model and the fastest-lap model to local storage.
  • Randomness is seeded. Each run's seed and full configuration are logged and exported with the episode and generation data.
SettingValue

07 / Known limits

  • Every episode starts from the same standing start, so early generations can overfit the opening sections. Random start positions are the next lever.
  • Walls end the episode, so the agent never learns recovery.
  • Flat 2D: no elevation, camber or tyre-temperature model.
  • The elites replay identically each generation, so they count towards the completion rate.
